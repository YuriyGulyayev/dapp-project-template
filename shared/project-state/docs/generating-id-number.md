# Generating an ID

## How to

To generate an ID, run from the workspace root folder:

```bash
npm run --silent --workspace shared generate-id-number
```

You also can run it from the `shared` folder without providing the `--workspace` param. The generated positive number will be printed by calling `console.info`.
